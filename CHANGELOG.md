# Changelog

What changed in each version of VibeCode Explorer. The newest version is at the top.

## 1.0.0 (2026-10-31)

The first release. Everything runs on your computer: nothing is uploaded and no AI is called.

- **Dashboard:** a graph of your JavaScript, TypeScript and Python files and their imports, with a details panel that explains each file in plain words.
- **Changes and history:** files added, changed or deleted, the latest commits, and before/after views of each change.
- **AI sessions:** your Claude Code prompts, tokens, security mentions and tips, plus a review checklist of the files each session changed.
- **Notes and issues:** your own notes on files and commits, and issues you can add, close and reopen, saved in `.vibecode/notes/` only after you allow it.
- **Files, Pages & APIs:** a folder tree, your app's pages with the files that make them, web routes, HTTP calls and database models.
- **Health:** VS Code's problems in plain words, a project checklist, secret-looking text (location only), possibly unused files, folder rules and safe points to go back to.
- **Project and Learn:** your plan's phases and current stage, how to run the project, a reading order, a test map, TODOs, packages and hotspots.
- **Open in Browser:** the same dashboard in your web browser on this computer, with code and changes shown on the page.
